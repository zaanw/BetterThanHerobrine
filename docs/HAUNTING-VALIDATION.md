# Проверки 0.4.0-beta.1

Дата: 2026-11-04. Базой послужил актуальный `main` — `89449f602f7d26a25694de810689922c3fbfdb1a`. Существующие watcher, команды, конфиги, сцены и схемы локальной памяти сохранены.

## Проверено в текущей машине

- Java 25: независимое ядро скомпилировано и запущено. 60 768 assertions в одном наборе, а не 60 768 независимых тест-кейса.
- Все стадии 30 сцен доставлены ровно один раз и освобождают слот.
- 30 000 секунд работы Director: конечное напряжение, лимиты сцен, cooldown, отключение, выход игрока.
- Однократные JOIN и звуки до конца первой минуты для 64 начальных вариантов одиночного мира, в том числе с условиями суперплоскости. Общий серверный лимит может отсрочить вступление при большом числе одновременных входов. Отключение хоррора, нулевая интенсивность и административная пауза имеют приоритет над вступлением.
- Проверка чистой политики доступа: `zaanw`/`ZAANW` без серверного разрешения запрещены; `za anw` и любой другой ник запрещены даже с разрешением.
- Запись и чтение истории/конфига, защита от некорректного файла, разные пресеты, сохранение отключённого хоррора и пользовательской громкости.
- Полное декодирование 16 mono Vorbis ресурсов, все sound paths, субтитры и EN/RU ключи, три PNG 64×64, entrypoint файлы.
- Повторная генерация звуков дала побайтово одинаковые OGG.
- Синтаксический разбор всех 34 Java-файлов средствами JDK. Это разбор без разрешения типов Minecraft/Fabric, **не полная компиляция**.
- `bash -n` сценариев и `git diff --check`.

## Блокер полной сборки

Настоящая `./gradlew clean build --no-daemon --console=plain` запущена на Java 25. Gradle завершился с кодом 1 на разрешении Loom `1.19-SNAPSHOT`; `https://maven.fabricmc.net/` через действующий прокси возвращает HTTP 403. Это происходит до выполнения задач Java-компиляции и clean. Лог: `docs/haunting-build.log` в текущей машине (игнорируется Git). Сетевые домены ранее сохранены в черновике среды, но отсутствуют среди активных custom allowed hosts.

Новая GitHub Actions конфигурация выполняет независимые проверки и `clean build`, затем сохраняет mod JAR только при успехе. Первый удалённый workflow 41893732040 дошёл до Java-компиляции и нашёл три несовпадения клиентского API: final template method кнопки, старый displayClientMessage и getter ID звука. Они исправлены через актуальный extractContents, gui.hud.setOverlayMessage и типизированное исключение собственных HorrorSound из приглушения. Успех следующего workflow пока не подтверждён. CI не выполняет графические игровые тесты.

## Требуется выполнить вручную после успешной компиляции

- [ ] Обычный Survival: заметное вступление в течение минуты, локализованное сообщение один раз, отсутствие постоянных молний.
- [ ] Суперплоскость, глубокая пещера, лес и деревня: корректные позиции и подбор событий; отсутствие принудительной загрузки чанков.
- [ ] Herobrine: отдельная модель, белые глаза, нормальные позы рук, режимы подхода/наблюдения, disappearance on look-away, новая точка Return.
- [ ] Наблюдатель за простым стеклом/стеклянной панелью. Цветное стекло пока не распознаётся пробой окружения.
- [ ] Админ с ником zaanw и полномочиями: F8 и все 10 функций, в том числе выбор события; команды `/bth admin watcher` и `/bth admin chaos`.
- [ ] Тот же ник без полномочий, другой ник с полномочиями и поддельные C2S запросы: отказ, нет игровых изменений.
- [ ] Звук: уже играющие ambient/music/weather/neutral плавно приглушаются и восстанавливаются; пользовательские настройки не записываются. Mixins используют внутренние поля SoundEngine и требуют особой проверки запуска на 26.3.
- [ ] EN/RU субтитры, reduced visuals, все пресеты и сохранение настроек после перезапуска.
- [ ] Stop All Events прекращает стадии, очищает сущности/эффекты и даёт 180 секунд паузы.
- [ ] Logout, смерть, смена измерения, остановка сервера: корректная очистка, нет дубликатов.
- [ ] Выделенный Fabric server с двумя клиентами, серверные лимиты, отзыв полномочий при активном оверлее.
- [ ] Логи без критических ошибок, приемлемая производительность, проверка звуковых/рендер mixins.

## Ограничения реализации

Глубинный туман и shader distortion не реализованы; экранные эффекты не выдаются за них. Ночь в адаптере оценивается по темноте неба, без выдуманного времени от возраста процесса. База — эвристика неподвижности; окно — ограниченный поиск обычного стекла/панели с проверкой линии взгляда при размещении. Полная совместимость новых API, рендерера и mixins не установлена, поскольку сборка остановилась до компиляции. Релиз не готов, JAR не создан, публикация не выполнялась.
