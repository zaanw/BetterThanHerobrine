# BetterThanHerobrine 0.4.0-beta.1 — draft

**Статус: не готов к публикации.** Полная clean build прошла в GitHub Actions для коммита 119f3b7; JAR находится в артефакте сборки. Игровые проверки не проведены, публикация пока не разрешена.

BetterThanHerobrine — психологический хоррор для Minecraft Java 26.3 на Fabric. Серверный Director наблюдает за контекстом игры, выбирает ограниченные по времени сцены и оставляет периоды спокойствия. Наблюдатель может стоять вдали, подходить, появляться за окном и исчезать, когда игрок отворачивается.

В исходниках этой версии:

- 30 сцен с условиями, задержками и cooldown, включая однократное вступление, The Observer, The Window, Silent Village, Doppelganger, Cave Visitor и The Return;
- отдельный EntityType `betterthanherobrine:herobrine`, модель и оригинальные текстуры;
- 16 оригинальных пространственных звуков, субтитры EN/RU, собственная громкость;
- серверная авторизация админ-панели F8: `zaanw` **и** права gamemaster/operator;
- уменьшение визуальных эффектов, рабочие Low/Normal/High/Nightmare presets;
- отсутствие постоянных изменений блоков, ограничение сущностей и активных сцен.

Требуются Java 25, Fabric Loader 0.20.1+ и Fabric API 0.165.0+26.3. Мод требуется на клиенте и сервере. Компиляция на целевой версии подтверждена; клиентская интеграция, модель, mixins звука и кнопки ещё требуют проверки во время игры. Глубинный туман пока не реализован: используется плавная экранная дымка. Doppelganger использует оригинальную тёмную человекообразную текстуру, а не загруженный с внешнего сервера скин конкретного игрока.

До публикации:

1. Успешная `./gradlew clean build` и JAR из текущего commit.
2. Игровые smoke-тесты по `docs/HAUNTING-VALIDATION.md`, включая аудио mixins.
3. Проверка описания и выбор лицензии проекта владельцем: открытая лицензия не назначалась автоматически.
4. Настройка существующего проекта Modrinth через `MODRINTH_PROJECT_ID` и защищённый Actions secret `MODRINTH_TOKEN`. Не вводить токен в чат или исходники.
5. Рекомендуется включить required reviewers для GitHub environment `modrinth-release`.
6. Только после проверки вручную запустить `publish-modrinth.yml`, указать точную проверенную версию и подтвердить игровые тесты. Push, PR и создание тега не публикуют Modrinth-релиз.

Это подготовленный текст версии, а не свидетельство успешной сборки или тестирования.
